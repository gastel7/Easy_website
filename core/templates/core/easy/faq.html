Questions fréquentes

Comment réserver un billet sur Easy ?

Ouvrez la page de l'événement qui vous intéresse, puis cliquez sur « Voir les détails ». Dans la rubrique « Réserve ton billet », choisissez la catégorie de billet et le nombre de billets, puis cliquez sur « Réserver mon billet ». Vous devez être connecté à votre compte pour réserver.

Puis-je annuler ou rembourser mon billet ?

Un remboursement est possible selon les conditions fixées pour l'événement par l'organisateur de l'événement. Les informations sur le remboursement sont affichées sur la page des détails de l'évenement concernée.

Comment recevoir mon billet après achat ?

Dès que votre paiement est confirmé, votre billet est valide immédiatement. Vous le retrouvez dans « Mes billets », avec son QR code. Présentez ce QR code à l'entrée, sur votre téléphone ou imprimé. Vous le recevrez par mail ou sur whatsapp selon vos préférences.

Est-ce sécurisé d'acheter sur Easy ?

Oui. Le paiement est sécurisé, et chaque billet a un QR code unique, vérifié à l'entrée, ce qui évite les faux billets. Vos données personnelles servent uniquement à la gestion de vos réservations. Notre équipe est disponible 24h/24 et 7j/7 pour vous aider.

Je suis organisateur, comment publier mon événement ?

Créez un compte, puis ouvrez le formulaire « Créer un événement ». Il vous guide en 4 étapes : informations, images et vidéo, billets, puis publication. Vous choisissez si l'événement est public ou privé. Une fois publié, il apparaît sur la plateforme.
